# (附文档)Springboot+Vue+MySQL 基于自话应加仅朴紊贝叶斯的商务邮件分类系统

### 系统简介

本系统是一套基于自适应加权朴素贝叶斯算法的商务邮件分类平台，采用前后端分离架构。系统通过中文分词与特征加权对邮件文本进行自动归类，支持多用户注册登录、邮件批量导入、在线分类预测与历史记录管理，并配套管理员后台进行用户与数据维护。
 
### 核心功能
 
### 普通用户端

 
- 注册与登录：支持账号注册、密码登录，登录状态由后端 Token 校验维持。 
- 邮件文本分类：在输入框粘贴或输入邮件正文，提交后调用分类接口返回预测类别与置信度。 
- 批量邮件导入：支持上传包含多封邮件的文本或表格文件，系统逐条解析并批量输出分类结果。 
- 分类结果查看：展示每封邮件对应的预测类别、概率分布及关键特征词。 
- 历史记录管理：查看本人历次分类记录列表，支持按时间与类别筛选。 
- 历史记录删除：可对单条或批量历史记录执行删除操作。 
- 个人信息维护：查看并修改昵称、邮箱等基础资料，支持修改登录密码。 
- 类别字典查看：查看系统当前支持的商务邮件类别及其说明。
 
### 管理员端

 
- 用户管理：查看用户列表，支持按用户名与注册时间筛选，可禁用或启用账号。 
- 用户信息编辑：修改指定用户的角色、状态与基础资料。 
- 邮件数据管理：查看全站邮件样本列表，支持按类别与关键词检索。 
- 样本标注维护：对训练样本的类别标签进行新增、修改与删除。 
- 类别管理：维护商务邮件类别字典，新增或停用分类标签。 
- 模型训练触发：手动触发朴素贝叶斯模型重新训练，查看训练状态与完成时间。 
- 分类记录审计：查看全部分类记录，支持按用户、类别与时间范围过滤。 
- 数据统计看板：展示邮件总量、各类别占比、分类调用次数等统计指标。 
- 停用词维护：管理分词停用词表，支持新增与删除停用词。
 
### 技术栈

 后端框架Spring Boot ORM 框架MyBatis-Plus 权限控制Token 鉴权 + 角色拦截 算法模型自适应加权朴素贝叶斯 中文分词分词组件 + 停用词过滤 前端框架Vue 状态管理Vuex 构建工具Vite 数据库MySQL
